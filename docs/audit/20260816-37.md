## 本轮完成

**ADR-005 Phase 6 生产路径落地（接口不变，切换实现）：**

- `core/security/ratelimit.py` 新增 `RedisTokenBucket`：
  - Lua 原子 read-modify-write（HMGET → 补充 → 消费 → HMSET + PEXPIRE），
    多进程/多实例跨进程一致
  - 桶粒度与内存实现一致：`ratelimit:{key}:{capacity}:{refill_per_s}` 组合键
  - TTL = 满桶时间 × 2 + 60s（防键提前过期 → 桶重置 → 变相补令牌；
    refill=0 保留一天）
  - clock 为墙钟（跨进程共享时间基准，测试注入确定值）
- `build_limiter(settings)`：`RAG_REDIS_URL` 非空 → ping 连通性检查 → Redis
  实现；任何异常 → 回退内存实现 + 告警（部署层 fail-open）；`socket_timeout=0.25s`
  （慢 Redis 快速失败进 fail-open，限流不得拖垮认证主链路）
- 依赖：`redis>=5.0` 入 uv.lock（纯 Python，CI 直接覆盖）
- 测试（+5 例）：stub 客户端验证协议面（键格式/TTL 计算/放行拒绝/fail-open/
  不可达回退）；Lua 语义由演练脚本对真机验证
- `scripts/drill_redis_ratelimit.py`：真实 Redis 演练（容量耗尽/时间补充/
  键隔离/TTL 存在/清理），对齐 pg_drill 先例
- user-guide.md §2 配置表补 RAG_REDIS_URL 行

**v1.1 规划项全部落地**：MCP streamable HTTP（34）+ BM25 倒排（36）+
限流 Redis 化（本轮）。

| L 演练脚本失败路径留脏键 | try/finally 清理 |
| L TTL 测试同义反复 | 改为具体值断言（260/180/86400） |
| 登记项 | 复合键字符串拼接歧义（当前调用点前缀不相交，无实际风险）；按 KB 维度限流列后续增强 |
