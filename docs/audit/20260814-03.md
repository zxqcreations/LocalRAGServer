## 重要环境发现（对后续阶段有直接影响）

**Windows 系统注册表代理（127.0.0.1:7897）会劫持 httpx 回环请求**：
- 代理配置在注册表（Internet 设置）而非环境变量——`urllib.getproxies()` 可读到，`os.environ` 读不到
- httpx 默认 `trust_env=True` 时，连 127.0.0.1 的本地请求也会被送进代理（respx pass_through 组合下直接崩溃）
- **处置**：全部本地服务 HTTP 客户端（ChatClient/TeiEmbedder/OpenAIEmbedder）显式 `trust_env=False`——企业级正确行为：出站网络路径显式控制，不依赖系统隐式配置
- **Phase 1+ 影响**：网页爬虫（出站）需要显式代理配置（RAG_* 配置项），不能依赖注册表；TEI/vLLM 等本地端点必须绕过代理
