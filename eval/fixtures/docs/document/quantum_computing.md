# 量子计算入门

## 什么是量子比特

量子比特（qubit）是量子计算的基本单元。与经典比特只能处于 0 或 1 不同，量子比特可以处于 0 和 1 的任意线性组合状态。量子比特的物理实现方式包括超导电路、离子阱和光量子系统等，其中超导量子比特是目前最主流的技术路线。量子比特的制备需要将物理系统冷却到接近绝对零度的温度，并通过精确的微波脉冲进行操控。

## 叠加态

叠加态是量子比特区别于经典比特的本质特性。一个处于叠加态的量子比特在测量前同时"存在"于多个状态，测量后才会坍缩到某一个确定状态。叠加态使得量子计算机能够并行处理指数级的状态空间，这是量子加速的来源之一。

## 量子纠缠

量子纠缠是多个量子比特之间的一种强关联：对其中一个比特的测量会立即决定另一个比特的状态，无论它们相距多远。量子纠缠是量子隐形传态和量子密钥分发的基础。

## 量子门与量子电路

量子门是对量子比特进行操作的基本单元，常见的单比特门包括泡利 X 门、哈达玛门和相位门，双比特门中最重要的是 CNOT 门。哈达玛门常用于制备叠加态，CNOT 门用于产生量子纠缠。量子电路由量子门按时间顺序排列构成，是量子算法的标准表示方式。

## 退相干与量子纠错

退相干是量子系统与环境相互作用导致量子信息丢失的过程，是量子计算面临的最大工程挑战之一。为对抗退相干，研究者发展了量子纠错技术，通过将逻辑量子比特编码到多个物理量子比特上，利用冗余信息检测并纠正错误。

## 应用前景

量子计算在多个领域有应用前景。在密码学中，肖尔算法能够在多项式时间内分解大整数，对 RSA 加密构成威胁。在材料模拟方面，量子计算机可以精确模拟分子和材料的量子性质，加速新材料与药物的研发。量子计算在优化问题、机器学习和金融建模领域同样被认为有潜力。
