# 机器学习基础

## 监督学习与无监督学习

监督学习使用带标签的数据进行训练，目标是学习输入到输出的映射，典型任务包括分类与回归。无监督学习处理无标签数据，目标是发现数据的内在结构，典型任务包括聚类与降维。数据集划分是机器学习流程的重要环节，常见做法是按比例划分训练集、验证集和测试集，例如 8:1:1 的划分比例。

## 过拟合与欠拟合

过拟合指模型在训练数据上表现很好，但在未见过的数据上表现差，即模型记住了训练数据的噪声。欠拟合则是模型过于简单，无法捕捉数据的规律，在训练集上表现就不佳。判断过拟合的常用方法是观察训练集与验证集的性能差距。

## 正则化

正则化是防止过拟合的主要手段。L2 正则化通过在损失函数中加上权重平方和项，鼓励模型使用较小的权重；L1 正则化则倾向于产生稀疏解。此外还有 Dropout、早停等正则化技术。

## 交叉验证

交叉验证是一种评估模型泛化能力的方法：将数据分成 K 份，轮流用其中一份做验证、其余做训练，重复 K 次取平均。交叉验证能更充分地利用数据，减少评估结果的方差。

## 评估指标

分类问题的常见评估指标包括准确率、精确率、召回率和 F1 分数。精确率衡量预测为正的样本中真正为正的比例，召回率衡量所有正样本中被正确找出的比例。F1 分数是精确率与召回率的调和平均。当类别不平衡时，准确率会失真，应优先使用精确率、召回率和 F1 分数。

## 数据预处理

特征缩放是许多算法的必要预处理步骤：梯度下降法在特征尺度差异大时收敛缓慢，距离类算法（如 K 近邻）会偏向数值大的特征。常用的特征缩放方法包括标准化和归一化。
